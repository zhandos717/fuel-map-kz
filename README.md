# Карта заправок Казахстана

Карта АЗС Астаны и Алматы, раскрашенная по тому, что пишут водители в Threads.

**Живая версия: [fuel-map-kz.web.app](https://fuel-map-kz.web.app)**

🟢 советуют · 🔴 жалуются · 🟠 мнения разошлись · ⚪️ в тредах не пишут

Тапаете точку — видите цитаты людей с датами, рейтинг 2ГИС и кнопку маршрута. Снизу список ближайших к вам заправок, можно оставить только зелёные. Три языка: русский, қазақша, English.

## Что внутри

351 точка, 19 сетей, вердикты по 17 сетям и 11 конкретным адресам. Vanilla JS, Leaflet, 38 КБ в gzip, ноль фреймворков. Работает офлайн как PWA.

Данные собираются из трёх источников: адреса и рейтинги из 2ГИС, пробелы закрывает OpenStreetMap, смысл дают отзывы из Threads. Координаты приезжают автоматически, **цвета ставятся руками** — ни один цвет не выводится формулой.

Подробности — в [PROJECT.md](PROJECT.md): методология вердиктов, устройство пайплайна, правовая позиция, известные ограничения.

## Запуск

```bash
python3 -m http.server 8000   # открыть localhost:8000
```

Пересборка данных (нужен `YANDEX_GEOCODER_KEY` в `../.env`):

```bash
python3 geocode.py     # places.json + manual.json → stations.js
python3 fill_gaps.py   # добор точек из OpenStreetMap
./deploy.sh            # выкладка на Firebase
```

## Оговорка

Сервис информационный. Данные взяты из публичных отзывов и открытых карточек 2ГИС, лабораторных исследований не проводилось. Цвета отражают мнения тех, кто писал отзывы, а не утверждение автора о качестве топлива. Владельцы АЗС могут прислать опровержение — оно попадёт в карточку.
